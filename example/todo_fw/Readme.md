# Todo

This is an todo app where user can register, login and start record their plan in as todo things to do.


# How to run

```sh
# direct to the example folder
cd example/todo_fw

# start docker
# ensure your docker application is running
make start-db

# run backend
make go-run

# install the dependencies of frontend-framework in advance
make install

# run frontend
make start
```
