# CodeProjects

This repository contains multiple coding projects merged together.

## Projects Included

### 1. Literary Lions
Web application project.

### 2. Javascript Sprint
Collection of JavaScript exercises and projects covering:
- DOM manipulation
- Array methods (map, filter, reduce)
- Object-oriented programming
- CSS animations and styling

### 3. Racetrack
Real-time race tracking system with WebSocket support.
Features:
- Front desk management
- Race control
- Lap tracking
- Public displays (leaderboard, countdown, flags)

### 4. TypeScript Sprint
TypeScript exercises covering:
- Type annotations
- Interfaces and types
- Generics
- Modules

### 5. Match-Me
A matching/dating application built with:
- **Frontend**: React + TypeScript + Vite
- **Backend**: Go + GraphQL
- **Features**: User profiles, matching algorithm, real-time chat, connections system

### 6. Frontend Framework
Additional frontend framework exercises and examples.
