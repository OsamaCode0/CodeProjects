# Frontend Framework

## Overview

A lightweight, vanilla JavaScript frontend framework for building reactive single-page applications (SPAs) with virtual DOM, state management, and component-based architecture.

For more details [click here](./framework/Readme.md) to see our framework readme file


## How To build

```sh
# from your root project
make build
```

## How to use

```sh
# Create your project folder
touch new-project

# Install frontend-framework package
cd new-project
npm install frontend-framework

# This files will be created inside your new-project
# 1. 📂 dist
#        frontend-framework.js
# 2. index.css
# 3. index.js
# 4. index.html
```
